# Series Profile

Derived from 8 transcripts: Madden 26 Cleveland Browns EP1–6, Madden 27 Washington
Commanders EP1–2. This file describes *how the series is built* — structure, pacing,
voice. The visual grammar lives in `edit-grammar.md`.

---

## Episode types

Four observed shapes. Identify which one the raw footage is before anything else,
because the skeleton differs.

### Type A — Series opener / roster tour
*Browns EP1 (24:45), Commanders EP1 (40:43)*

No gameplay at all. Pure roster evaluation over menus.

| Segment | Typical duration |
|---|---|
| Cold open — team framing, doom-and-gloom premise | 0:00–0:20 |
| Welcome + like/subscribe | 10–15s, lands by ~0:35 |
| Cross-promo (College Football dynasty tie-in) | 30–60s |
| Why this team was chosen | 60–90s |
| Head coach creation — *always* a created coach, never the default | 90–150s |
| Position tour: QB → RB → WR → TE → OL → DL → LB → CB → S → ST | bulk of episode |
| Draft capital / future assets | 60–90s |
| Next-episode setup | 30–60s |
| Outro CTA → "Peace out" | ~15s |

The position tour is the episode. Each position group runs 90s–4min depending on
talent. Star players get their own extended beat with career history.

### Type B — Preseason
*Browns EP2 (59:11), Commanders EP2 (52:11)*

Games exist but they are **evidence for roster decisions**, not the story.

Cold open → recap → storylines/plan → roster moves → game 1 → postgame eval →
game 2 → postgame eval → game 3 → postgame eval → **53-man cuts** → next setup → outro.

The cuts section is the payoff. Treat it as a headline segment, not an afterthought.

### Type C — Regular season
*Browns EP3–6 (46:08, 1:09:30, 54:25, 48:13)*

Cold open (names today's matchups) → recap → roster/FA moves → opponent preview →
**game** → halftime report → **game** → postgame analysis → weekly recap →
next opponent → outro.

Repeat the game block per game. Two games is the norm, three when they're blowouts.

### Type D — Prospect profile
*Embedded in Browns EP5 at 0:15–23:39*

A draft-class segment spliced into a normal episode, before the game. Runs
tier-by-tier: big three → first-round fringe → day two → day three → future
classes. Each prospect gets measurables, college history, a pro comparison.

## Timing model

| Beat | Duration |
|---|---|
| Cold open before first CTA | 20–35s |
| Time to first gameplay | 3:30–5:40 |
| Single game block | 15–22 min |
| Halftime report | 60–90s |
| Postgame analysis | 90–150s |
| Weekly recap (around the league) | 90–120s |
| Next-opponent preview | 60–150s |
| Outro | 12–20s |

Compression target: a 45–55 min raw recording becomes a 20–25 min episode for a
one-game Type C, or 45–60 min for a multi-game episode. Most of the reduction
comes from dead gameplay, menu navigation, and play-selection — not from cutting
commentary.

## Voice

**Address.** First person plural for the team ("we're going to go for it", "our
defense"). Second person to the audience ("you guys"). Present tense for
play-by-play, past for analysis.

**Register.** Broadcast play-by-play voice during games — he *is* the commentator,
not a reactor. Analyst voice in postgame. Conversational in roster segments.

**Self-deprecation about the team is constant** and it's the show's tone. "Doom and
gloom." "We've kind of put the bar on the floor." "The offense looks lifeless."
Never sanitize this.

### Recurring bits — preserve these, they're the brand

- "Wacko for Flacco" — every Flacco appearance
- "Big Booty Judy" — Jerry Judy
- "The King has entered his castle" — Derrick Henry touchdown
- "Sonic and Knuckles" — Gibbs & Montgomery
- "You got barbecue back there and you didn't invite me" — Denzel Ward
- "Ball don't lie" — after a penalty/turnover reverses fortune
- "I apologize, I was not familiar with your game" — an unknown player makes a play
- "One man's trash is another man's treasure" — free agency
- "Welcome to the NFL, [rookie]" — a rookie's first big play
- "Risk it for the biscuit" — going for it on fourth down
- "That, my friends, is called progress"
- "Peace out" / "Peace out, dog pound" — hard episode end

### Comedic register

Four flavors, all present in every episode:

1. **EA/Madden bug complaints** — wrong stat graphics, absurd halftime highlights,
   silver helmets, players celebrating nothing. "Good job, EA."
2. **Real-world tangents** — a player shares a name with someone famous, and he
   detours ("Chris Paul, 12-time NBA All-Star").
3. **Fourth-wall breaks** — "I'll break the third wall for a second", explaining a
   misclick or that he wasn't controlling a defender.
4. **Roasting his own team** — the primary engine.

## CTA placement

| CTA | Position | Wording |
|---|---|---|
| Opening | 0:06–0:36 | "Make sure to hit the like button, subscribe to the channel if you are new" |
| Closing | final 15–25s, immediately before "Peace out" | "Make sure to leave a like, subscribe to the channel if you are new" |
| Engagement question | end of episode, before closing CTA | "Let me know in the comments" — asks a real decision (who should start at QB?) |
| Sponsor read | ~4:50–6:30 when present | Only observed in Commanders EP1 |

The engagement question is always a genuine franchise decision the audience can
weigh in on, and the next episode *acts on the answer*. Preserve any moment where
he references what the comments said.

## Narrative continuity

- Every episode opens by naming what happened last episode.
- Cross-series continuity is load-bearing: College Football dynasty players enter
  the NFL draft classes. Prospect profiles reference the dynasty series by name.
- Prior franchise series are referenced constantly ("we had him in the Broncos
  franchise", "Dragons series in Madden 24"). These callbacks are part of the voice.
- Episodes end by naming the next opponent and often flag uncertainty about
  episode structure ("I think we're going to play two games").
